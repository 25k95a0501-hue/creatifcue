==================================================

TYPOGRAPHY

==================================================

Typography is extremely important.

Use a modern high-quality grotesk/sans-serif for:

• Navigation

• Main headings

• Body copy

• Buttons

• Labels

Use an elegant editorial serif italic for selected words.

The serif should NOT be used everywhere.

Use it strategically to create contrast.

For example:

“WE BUILD”

“brands people remember.”

The first part can be bold modern sans-serif.

The emphasized phrase can use elegant serif italic.

Create strong typography hierarchy.

Use:

• very large display headings

• medium section headings

• small uppercase labels

• restrained body copy

Do not use too many font styles.

Maintain a consistent typography scale throughout the entire website.

==================================================

LAYOUT SYSTEM

==================================================

Use a sophisticated responsive grid.

Desktop:

Large margins.

Asymmetric columns.

Large whitespace.

Different image widths.

Editorial alignment.

Do not center everything.

Use sections that sometimes begin from the left and sometimes from the right.

Use intentional vertical offsets.

Use overlapping elements only where they improve the composition.

Tablet:

Simplify the asymmetry while maintaining editorial character.

Mobile:

DO NOT simply stack the desktop layout.

Create a dedicated mobile composition.

Mobile must have:

• excellent typography

• correct spacing

• readable text

• horizontally scrollable portfolio where appropriate

• clean navigation

• properly sized images

• no horizontal overflow

• no overlapping elements that become unusable

• accessible buttons
